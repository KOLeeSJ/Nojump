# Skill: Logging & Summary (로그 요약)
 
## 목적
작업 진행 상황, 에러, 그리고 결정 사항을 표준화된 양식으로 기록하여 추적 가능성을 확보하고 세션 간의 협업 효율을 높입니다.
 
## 실행 시점
주요 태스크가 완료되었거나 세션을 종료하기 직전에 실행합니다.
명령어: "로그 요약해"
 
## 단계별 절차
 
### 1. 작업 업데이트 (`work/update.md`) - 필수
- 목표, 변경 사항(파일/로직), 현재 상태, 그리고 다음 단계를 기록합니다.
- 형식: `## Addendum (YYYY-MM-DD) - [작업 제목]`
 
### 2. 할 일 추적 (`architecture/todolist.md`) - 필수
- 완료된 태스크를 `[x]`로 표시합니다.
- 새롭게 발견되거나 계획된 태스크가 있다면 `[ ]`로 추가합니다.
 
### 3. 에러 기록 (조건부)
- **Trigger**: 빌드 실패, 런타임 에러, 테스트 실패 발생 시.
- **Action**: `test/errorlogs/`에 상세 로그를 남기고, `test/learn-from-log.md`에 방지책을 추가합니다.
 
### 4. 에이전트 실수 기록 (조건부)
- **Trigger**: 도구 오용, 경로/스펙 불일치, 할루시네이션 발생 시.
- **Action**: `agent/mistakes-arrest.md`에 인시던트 내용과 재발 방지 규칙(Arrest Rule)을 기록합니다.
 
### 5. 의사결정 요약 (조건부)
- **Trigger**: 아키텍처 변경이나 전략적 전환이 있었을 때.
- **Action**: `requirements/decisions.md`를 업데이트하고, 필요 시 `requirements/debates/`에 논의 과정을 요약합니다.
