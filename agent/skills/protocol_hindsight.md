# Skill: Hindsight (톺아보기)
 
## 목적
과거 로그를 분석하여 현재의 위치를 재파악하고 다음 최적의 행동을 결정합니다.
 
## 실행 시점
- 작업 중 방향성을 잃었을 때.
- 사용자가 "톺아보기"라고 요청할 때.
 
## 단계별 절차
1. **Log Analysis**: `work/update.md`와 `test/learn-from-log.md`를 최근 3개 세션 분량만큼 분석합니다.
2. **Current Status**: 현재 마일스톤에서의 진행률을 계산합니다.
3. **Bottleneck Identification**: 현재 가장 큰 장애물이나 지연 요인을 파악합니다.
4. **Action Planning**: `architecture/todolist.md`의 우선순위를 재조정하거나 다음 단계를 명확히 제안합니다.
