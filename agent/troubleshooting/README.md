# Troubleshooting Logs
 
이 폴더는 작업 중 직면했던 복잡한 버그, 환경 설정 문제, 프레임워크(Nexacro, React 등)의 난해한 동작 등을 해결하기 위해 겪었던 과정과 최종 해결책을 기록하는 공간입니다.
 
## 왜 기록해야 하나요?
- 동일한 에러나 설정 문제로 다음 에이전트(또는 작업자)가 수시간을 낭비하는 것을 방지합니다.
- `mistakes-arrest.md`가 '에이전트의 규칙 위반이나 판단 실수'를 기록한다면, 이 폴더는 **'시스템적, 기술적인 난제와 해법'**을 상세히 기록하는 지식 창고입니다.
 
## 기록 양식 (예시)
파일 이름: `YYYY-MM-DD_이슈_요약.md` (예: `2026-04-30_nexacro_dataset_binding_error.md`)
 
- **Symptom (증상)**: 발생한 에러 메시지와 현상
- **Context (상황)**: 언제, 어떤 조작을 했을 때 발생했는가?
- **Attempts (시도)**: 문제를 해결하기 위해 시도했던 실패한 방법들 (매우 중요함 - 중복 시도 방지)
- **Solution (해결책)**: 최종적으로 찾아낸 올바른 원인과 해결 코드/설정
