# Requirements & Decisions
 
이 폴더는 프로젝트의 요구사항을 정의하고, 발생하는 모든 의사결정을 기록하는 공간입니다.
 
## 주요 파일 및 역할
- **current.md**: 현재 구현해야 할 유효한 요구사항들의 요약입니다.
- **decisions.md**: 프로젝트 진행 중 결정된 주요 사항들을 기록합니다. (결정 일자, 내용, 근거)
- **debates/**: 요구사항이 불명확하거나 상충할 때, 에이전트와 사용자 간의 논의 과정을 기록하는 폴더입니다.
 
## 원칙
- 모든 기술적 구현은 `current.md`와 `decisions.md`에 명시된 요구사항을 바탕으로 합니다.
- 불명확한 부분은 추측하지 말고 `debates/`에서 논의하여 결론을 도출합니다.
