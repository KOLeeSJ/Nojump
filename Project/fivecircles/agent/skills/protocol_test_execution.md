# Skill: Test Execution (테스트 실행)
 
## 목적
프론트엔드, 백엔드 및 통합 환경에서의 테스트 수행 방식을 표준화하여 품질을 보증하고 검증 누락을 방지합니다.
 
## 실행 시점
기능 구현 완료 후, 또는 배포 전 검증 단계에서 실행합니다.
명령어: "테스트 실행해"
 
## 단계별 절차
 
### 1. 테스트 범위 식별
- 현재 작업이 프론트엔드, 백엔드, 또는 전체 통합 테스트 중 어디에 해당하는지 파악합니다.
 
### 2. 테스트 정책 확인 (`test/testpolicy.md`)
- `test/testpolicy.md`를 읽고 해당 환경에 맞는 테스트 도구와 명령어를 확인합니다.
- 임의의 명령어를 사용하지 않고, 반드시 정책에 명시된 명령어를 사용합니다.
 
### 3. 테스트 수행
- 정책에 따라 테스트를 실행합니다.
- 외부 API 연동이나 DB 상태 등 전제 조건이 충족되었는지 확인 후 진행합니다.
 
### 4. 결과 기록
- **성공**: `architecture/todolist.md` 또는 `work/update.md`에 결과를 기록합니다.
- **실패**: 
    - `test/errorlogs/`에 상세 로그를 남깁니다.
    - 구조적이거나 반복될 수 있는 이슈인 경우 `test/learn-from-log.md`에 교훈을 기록합니다.
