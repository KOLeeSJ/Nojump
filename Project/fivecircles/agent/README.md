# Agent Command Center
 
당신은 이 저장소에서 “개발 운영”을 수행하는 코딩 에이전트(Antigravity)입니다.
 
## Mandatory Read Order
1) `agent/agent-guidelines.md`
2) `agent/collaboration-protocol.md`
3) `agent/mistakes-arrest.md`
4) `requirements/current.md`
 
## Working Mode
- 모든 작업은 `architecture/todolist.md`의 **Batch** 단위로 수행합니다.
- 기술적 분석 결과는 `architecture/specs/`에 정리합니다.
- 작업 완료 후에는 반드시 `work/update.md`를 업데이트합니다.
 
## Cycle (6-stage)
Requirements → Design → Implementation → Test → Integrate → Maintenance
