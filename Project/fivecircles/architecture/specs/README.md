# Technical Specifications (Specs)
 
이 폴더는 프로젝트의 기술적 분석 결과와 설계를 상세히 기록하는 공간입니다.
 
## 상세 가이드라인
1. **API 설계**: 엔드포인트, 요청/응답 형식, 에러 코드 등을 기록합니다.
2. **DB 설계**: 테이블 스키마, 인덱스 정책, ERD 등을 기록합니다.
3. **로직 설계**: 복잡한 알고리즘이나 비즈니스 로직의 흐름을 기술합니다.
 
## 원칙
- 구현 전에 스펙을 먼저 작성하고, 사용자의 승인을 받는 것을 원칙으로 합니다.
- 스펙은 항상 최신 코드를 반영해야 합니다. 코드 변경 시 스펙도 함께 업데이트하세요.
