# Agent Scoring Policy
 
에이전트의 자율성을 높이고 작업 품질을 정량적으로 유지하기 위한 인센티브 시스템입니다.
 
## 1. 점수 체계 (Point Matrix)
 
| 범주 | 항목 | 점수 | 비고 |
| :--- | :--- | :--- | :--- |
| **Progress** | 태스크 1개 완료 | +30 | `todolist.md` 기준 분해된 단위 태스크 완료 시 |
| **Quality** | 필수 테스트 통과 | +40 | Unit/Integration 로그 확보 시 |
| **Quality** | 핵심 평가축 검증 | +50 | 주요 아키텍처나 Hard Gate 조건 완벽 충족 시 |
| **Violation** | 스펙/정책 위반 | -120 | 권위 있는 문서(`guidelines`, `current.md`) 위반 시 |
| **Efficiency**| 반복 실수 | -80 | `mistakes-arrest.md`에 있는 실수를 3회 이상 반복 시 |
 
## 2. 권한 레벨 시스템
점수 누적에 따라 에이전트의 자율성과 접근 권한이 확장됩니다.
 
| 레벨 | 필요 점수 | 권한 |
| :--- | :--- | :--- |
| **Lv0** | 0 - 99 | 단일 태스크만 수행 가능, 복잡한 설계 불가 |
| **Lv1** | 100 - 299 | 다중 단계 태스크 묶음 처리 가능 |
| **Lv2** | 300 - 599 | 크로스 서비스(프론트/백 동시 등) 아키텍처 작업 가능 |
| **Lv3** | 600+ | 새로운 기술 스펙 진화안을 주도적으로 제안 가능 |
 
## 3. 점수 기록
작업 종료 전("울트라 기록해" 스킬 발동 시), 스스로 이번 세션의 점수를 계산하여 `scoring/log-score.md`에 누적 기록합니다.
