# Architecture & Planning
 
이 폴더는 프로젝트의 기술적 설계와 실행 계획을 관리하는 공간입니다.
 
## 주요 파일 및 역할
- **todolist.md**: 프로젝트의 마일스톤과 세부 태스크(Batch)를 관리합니다. 에이전트의 모든 작업은 여기서 시작됩니다.
- **specs/**: API 명세, DB 스키마, 시스템 아키텍처 등 구체적인 기술 설계 문서를 보관합니다.
 
## 작업 흐름
1. 요구사항에 기반하여 `specs/`에 기술 설계를 먼저 고정합니다.
2. 설계된 내용을 바탕으로 `todolist.md`에 수행할 작업을 작게 쪼개어 등록합니다.
3. 작업이 진행됨에 따라 상태를 업데이트합니다.
