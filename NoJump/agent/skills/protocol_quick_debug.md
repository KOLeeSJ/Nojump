# Skill: Quick Debug (빠른 디버깅)
 
## 목적
과거의 실수 기록(Mistakes Arrest)과 학습 로그(Learn From Log)를 활용하여 동일한 에러를 두 번 해결하지 않도록 하고, 문제 해결 속도를 극대화합니다.
 
## 실행 시점
컴파일, 런타임, 또는 테스트 에러가 발생한 즉시 실행합니다.
명령어: "빠른 디버깅해"
 
## 단계별 절차
 
### 1. 지식 베이스 스캔 (Knowledge Scan)
- `agent/mistakes-arrest.md`를 읽어 반복적인 에이전트/운영 실수가 있었는지 확인합니다.
- `test/learn-from-log.md`를 읽어 과거에 동일하거나 유사한 기술적 이슈가 해결된 적이 있는지 확인합니다.
 
### 2. 패턴 매칭 (Pattern Matching)
- 에러 메시지의 키워드를 사용하여 위 문서들에서 검색합니다.
- **일치 항목 발견**: 기록된 해결책(Arrest/Solution)을 즉시 적용합니다.
- **일치 항목 없음**: 표준 디버깅 절차(로그 분석 -> 코드 확인 -> 테스트)로 진행합니다.
 
### 3. 적용 및 검증
- 수정한 내용을 반영하고, 실패했던 테스트 케이스를 다시 실행하여 해결 여부를 확인합니다.
 
### 4. 지식 업데이트
- **새로운 에러**: `test/learn-from-log.md`에 현상, 원인, 해결책을 새롭게 기록합니다.
- **반복된 에러**: 기존 기록의 발생 횟수를 업데이트하고, 왜 재발했는지 원인을 분석하여 기록합니다.
