# Skill: Operation Initialization (운영방침 초기화)
 
## 목적
새로운 세션을 시작할 때 에이전트의 역할, 프로젝트의 맥락, 그리고 운영 규칙을 빠르게 숙지하여 컨텍스트 유실을 최소화합니다.
 
## 실행 시점
- 세션 시작 시.
- 또는 사용자가 "운영방침 초기화해"라고 명령할 때.
 
## 단계별 절차
 
### 1. 부트스트래핑 (`README.md`)
- 루트 디렉토리의 `README.md`를 읽어 프로젝트 구조와 기본 운영 철학을 파악합니다.
 
### 2. 가이드라인 및 워크플로우 숙지
- `agent/README.md`와 `agent/agent-guidelines.md`를 읽어 행동 수칙과 제한 사항을 이해합니다.
- `agent/collaboration-protocol.md`를 통해 세션 간 핸드오프 규칙을 확인합니다.
 
### 3. 현재 상태 로드
- `work/update.md`를 읽어 가장 최근의 변경 사항과 히스토리를 파악합니다.
- `architecture/todolist.md`를 읽어 현재 진행 중인 태스크와 우선순위를 확인합니다.
 
### 4. 준비 완료 보고
- 읽기 과정을 마친 후: "운영 문맥 초기화 완료. 현재 프로젝트의 상태는 [상태 요약]이며, 다음 우선순위 작업인 [태스크명]을 수행할 준비가 되었습니다."라고 보고합니다.
