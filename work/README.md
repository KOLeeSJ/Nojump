# Work Logs & Policies
 
이 폴더는 실제 작업의 실행 기록과 정책을 관리합니다.
 
## 주요 파일 및 역할
- **update.md**: 가장 자주 사용되는 파일입니다. 각 세션의 작업 결과를 `Addendum` 형식으로 기록하여 히스토리를 관리합니다.
- **workpolicy.md**: 코딩 스타일, 커밋 규칙, 보안 정책 등 실무 지침을 보관합니다.
 
## update.md 작성 가이드
- 작업이 끝나면 반드시 날짜와 제목, 변경된 파일(refs), 테스트 결과를 포함하여 기록하세요.
- 이는 다음 세션 에이전트가 당신의 작업을 이어서 하기 위한 핵심 데이터가 됩니다.
